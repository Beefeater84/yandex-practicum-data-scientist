## EDA ( exploratory data analysis )

1. Получение общей информации о данных
	1. Пишем цели исследования
	2. Пишем ожидаемые данные
2. Загрузка и знакомство с данными
3. Предобработка данных
	1. Нормализация данных
		1. Обрабатываем типы данных
	2. Обработка пропусков
	3. Обработка явных и неявных дубликатов
	4. Анализ столбцов и данных
		1. Числовые - Распределение ( гистограмма, ящик с усами ), Основные показатели ( min / max / mean / median / describe ).
		2. Категориальные - проверить уникальные значения, нормализовать ( lower/ replace / strip )
4. Анализ закономерностей
	1. Изучение корелляции, построение матриц значений
	2. Построение трендов
	3. Анализ агрегированных данных, сводных таблиц
	4. Выписываем все новые гипотезы, которые возникают
5. Написание выводов

## Рекомендации при EDA
- Визуализируем данные. Так всегда проще что-то узметить. Чаще всего используют гистограммы, диаграммы размаха и рассеивания, графики временных рядом, тепловые карты [[Виды графиков]]
- На этот этап уходит огромное количество времени. Поэтому нужно его оценить и заложить.
- Всегда четко формулируем задачу, уточняем ее.
- Ограничить глубину анализа. Анализ можно проводить бесконечно - долго копаться в данных, все разбирать. Поэтому важно найти золотую середину и себя ограничить. Фокусируемся на ключевых параметрах.
