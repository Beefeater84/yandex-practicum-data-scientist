В зависимости от нашего датасета и от того какой тип данных нужно найти, выделяют 2 типа задач:
## Обучение с учителем ( supervised learning )

Главное в этом методе  - мы знаем целевую переменную. 
Нужно предсказать цену квартиры? у нас есть набор с известными ценами
Нужно предсказать спам или нет? у нас есть набор писем с известным результатом.

Если у нас есть правильные ответы - то мы можем натрериновать модель предсказывать конкретный результат.

Датасет, в котором известна целевая переменная - называется размеченным

### Регрессия

[[МО - линейная регрессия]]
Если нужно нужно узнать какое-то число в определенном диапазоне.
- Время доставки
- Количество проданного товара
- Курс валюты

### Классификация

Если нужно определить объект, к определенной категории.
Список категорий - заранее известен! И модели нужно научиться выбирать правильную в зависимости от признаков.

- Бинарные классификации [[МО - Бинарная классификация]]\
	- спам / не спам
- Многолассовые
	- тип картины - кубизм / импрессионизм / классика


## Обучение без учителя ( unsupervised learning )

мы не знаем правильный ответ целевой переменной. 
задача МО, изучить датасет, понять как данные связаны с целевой переменной.

Решаем задачи категоризации

Датасет, где правильный ответ целевой переменной неизвестнен - называется неразмеченным

### Кластеризация

Модель разделяет датасет по группам на основе признаков. Группы заранее неизвестны - модель сама определяет количество и по каким признакам разделить.

Т.е. модель не предсказывает какой-то признак, а разделяет существующий датасет - по группам.

- рекомендательные системы ( на основе похожих пользователей )
- сжатие файлов без потери качества звука
- выявление тематики похожих статей

### Снижение размерности

Задача уменьшить количество признаков в датасете без потери качества этого датасета.

## Обучение с подкреплением

в нем моделируется поведение агента в среде. 
Агент меняет срезу -> получает обратную связь.

- Игра в шахматы. Агент делает ход -> получает обратную связь от среды стало ли хуже или лучше.
