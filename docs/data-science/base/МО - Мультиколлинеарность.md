**Мультиколлинеарность** — это ситуация, когда два или более признаков сильно коррелируют между собой, то есть содержат очень похожую информацию.

Например у машины:
- объем двигателя
- скорость
- количество лошадиных сил

Это все очень связанные данные. 

В чем с ними проблема:  Модель не может решить какой из них определяющий. И она при одной итерации пожет посчитать важным 1, а второй почти 0, зато при другой итерации (  дообучении ) резко поменять веса! 

Это называется "нестабильная модель"

## Решение мультиколлениарнеости

Используют регуляцию с L2 [[МО - Регуляризация линейной регрессии]]
Она сглаживает веса и не дает им скакать.
