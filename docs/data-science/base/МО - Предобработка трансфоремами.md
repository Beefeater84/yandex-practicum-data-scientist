У нас есть 1 класс трансформер и мы ему задачем с каким столбцом что делать.
И он уже автоматически - удаляет пропуски, масштабирует, обрабатывает категории, разделяет выборки.

**Важные детали:**
- Как и другие инструменты обработки, `SimpleImputer` нужно обучать только на обучающих данных, а затем применять к валидационным и тестовым. Это важно, потому что при обучении вычисляются статистики для заполнения пропусков (среднее, медиана). Если обучать класс на всей выборке сразу, в эти статистики может попасть информация из тестовых данных, что приведёт к некорректной оценке качества модели.
- Обработка выбросов делается вне трансформера. Это не просто трансформация признаков, а исправление самих данных. Такие действия безопаснее выполнять на этапе подготовки данных до пайплайна.
- Порядок обработчиков имеет значение. Например, масштабирование должно идти после обработки пропусков. Это связано с тем, что большинство методов масштабирования (такие как `StandardScaler` или `MinMaxScaler` ) не могут работать с пропущенными значениями и вызовут ошибку, если встретят `NaN`. Поэтому первым этапом всегда должна идти обработка пропусков, а затем уже масштабирование или другие преобразования, зависящие от заполненности данных.

Рекомендуемый порядок обработки признаков обычно такой:
1. Обработка пропущенных значений.
2. Кодирование категориальных признаков.
3. Масштабирование числовых признаков.

Такой порядок позволяет избежать ошибок в автоматизированной обработке данных.


Выглядит это примерно так 

```python

preprocessor = ColumnTransformer(
    transformers=[
	    # это фиксированные кортежи
        (<название этапа>, <объект для преобразования>, <список колонок>),                   ...,               
    ]
)

```

```python
imputer = SimpleImputer(strategy='mean') # объект для заполнения пропусков 
scaler = StandardScaler() # объект для масштабирования 
target_encoder = TargetEncoder() # объект для кодирования категорий 

# Объединяем все преобразования в одном трансформере 
preprocessor = ColumnTransformer( 
	transformers=[ 
		('impute_age', imputer, ['age']),
		('scale_salary', scaler, ['salary']), 
		('encode_city', target_encoder, ['city']) 
	] 
)

```

В этом коде создаём трансформер `preprocessor`, в котором:

- для колонки `age` пропуски заменяются средним значением;
- для колонки `salary` применяется стандартизация;
- для колонки `city` используется `TargetEncoder`.

## Pipeline Transformer

```python
# Создаём ColumnTransformer для обработки признаков
preprocessor = ColumnTransformer(...)

# Создаём модель 
model = LinearRegression()

# Объединяем предобработку и модель в пайплайне  
pipeline = Pipeline(steps=[
    ('preprocessing', preprocessor), # сначала обработчик (preprocessor)
    ('classifier', model)            # затем модель
])

```
