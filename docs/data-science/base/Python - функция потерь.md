## MAE 

```python
import numpy as np
y_true = np.array([3, -0.5, 2, 7])
y_pred = np.array([2.5, 0.0, 2, 8])

# Вычислить ошибки для каждого объекта: для каждой пары значений из `y_true` и `y_pred` вычислить разницу.
errors = y_true - y_pred

# Взять модуль ошибок с помощью
abs_errors = np.abs(errors) 

# Усреднить полученные на предыдущем шаге абсолютные ошибки по всем объектам с помощью
mae = np.mean(abs_errors) 

print(f"MAE: {mae:.3f}")
```


При расчёте MAE можно допустить ряд типичных ошибок:

- Не вычислить абсолютное значение ошибки. Если не взять модуль, ошибка будет считаться с учётом знака. В таком случае отрицательные и положительные ошибки взаимно компенсируются, и MAE будет занижена.
- Не усреднить значения по всем объектам. Например, можно вычислить сумму абсолютных ошибок, но не разделить её на количество объектов. Тогда получится сумма ошибок, а не средняя ошибка.
