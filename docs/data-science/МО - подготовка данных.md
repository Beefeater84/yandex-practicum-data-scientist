## Предобработка данных

[[Pandas - предобработка данных]]

- перевод всех данных в чисовые значения. машинное обучение не понимает текст
- удаление всех пропусков, машинные модели не работают с пропусками (или очень снижает точность)
- удаление дубликатов
- удаление выбросов ( это тоже очень сильно снижает точность, потому что выбросы - это не типичные значения )
