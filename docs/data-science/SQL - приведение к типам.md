Приведение к типам через CAST

```SQL
-- Тип date
-- Даты можно задавать в любом формате, главное потом приводить их с помощью CAST
SELECT CAST('October 19, 2004' AS date),
       CAST('2004-Oct-19' AS date),
       '20041019'::date;
       
-- Результат всегда будет в формате ISO: 2004-10-19
```

Приведение к типам через `:` 

```SQL

SELECT AGE('2024-05-08'::date, '2024-01-06'::date); 

```
