Классические открытые датасеты для обучения и первых проектов:

- **Iris Dataset (Ирисы Фишера)** — предсказание вида цветка по морфологическим признакам. Один из самых известных и старых наборов данных.
- **Titanic** (Kaggle) — прогноз, выжил ли пассажир «Титаника», по характеристикам: возраст, пол, класс билета и другие. Классический пример задачи бинарной классификации.
- **MNIST** — база изображений рукописных цифр (0–9). Классическая задача компьютерного зрения.
- **Wine Dataset** — классификация сортов вина по химическим характеристикам.
- **CIFAR-10** — изображения десяти классов объектов (самолёты, машины). Используется для знакомства с нейросетевым обучением.
