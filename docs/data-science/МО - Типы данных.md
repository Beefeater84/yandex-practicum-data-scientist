## Количественные 

Количественные (они же числовые) - 
Главное отличие - мы можем их сравнить. Можем сказать что одно больше другого. Например Индекс - не числовое
### Непрерывные переменные

Могут принимать любое значение в определённом диапазоне. 
Например: рост, вес, температура.

### Дискретные переменные

Дискретные переменные принимают определённые значения. 
Например: количество детей, число проданных товаров. Нельзя принять 2.3 ребенка. Это всегда какой-то набор чисел.


## Категориальные

Категориальные ( они же номинальные ) - когда есть ограниченный список данных. ( Если в датасете всего 1 чисело, например от 1 до 5 - то это тоже категориальные, просто каждое число соответстует своей категории )

Сюда относятся: Марка автомобиля, Цвет

### Логические, Булевы 

Логические - булевы, причем могут быть 1:0 ( Они  )
### Ранговые

Ранговые (они же порядовые) - когда категориальные выстроены по степени важности. но расстояния между ними необязательно равны. Например: уровень образования: среднее, высшее, учёная степень.

### Особенности

Категориальные между собой не сравнить. Нельзя сказать что каое-то число в них больше другого. 

Разбиение на бины ( beam ) - когда мы берем числовой тип и разбиваем на группы. Например берем колонку возраста и разбиваем на группы ( детсад, школа, студент, рабочий, пенсионер ) [Data binning - Wikipedia](https://en.wikipedia.org/wiki/Data_binning)
